## 第零章 ⭐ 给 Agent 的（读完这一章就够动**手**了）

## 0.1 三个词（先立词汇）

| 词 | 定义 |
|---|---|
| **挂板** | **专门用来盛放挂表的界面**。它是容器，不是内容。 |
| **挂表** | **一张能交互、能提交反馈的表** —— 能勾选、能写备注、点提交后**有东西落盘**。 |
| **链接** | **把一张挂表挂上挂板的动作**。（"把它挂上去"） |

> **⚠ 最容易错的一点**：**"一张漂亮的 HTML 页面"不是挂表。**
> **挂表必须能**交互 + 提交 + 落盘**。少了提交链，它就只是网页。**

## 0.2 当用户这么说，你要这么做

| 用户说 | 你做 |
|---|---|
| **"用挂表问我"** / **"做个表给我填"** / **"列出来我勾"** | **造一张挂表** → **链接到挂板** → 告诉用户"已挂到挂板，打开看" |
| **"给我一份 checklist，我们对照着打勾、写评语"** | 造**清单型**挂表（多行勾选 + 每行备注） |
| **"一份验收表，逐项验收并评价，另有评论区我要打字"** | 造**验收型**挂表（勾选网格 + 大文本区） |
| **"批注表，我要按段落批注"** | 造**批注型**挂表（分段落 + 每段一个文本区） |
| **"挂板上有什么"** | 列挂板上的表（调 `/dsh-fou/panels`） |
| **"在浮游里打开这个链接"** | 挂一个 `kind:"url"` 条目（见 §三） |

**→ 用户说的可能是**任何说法**。**你的判断依据不是"他用了哪个词"，是"他要一张能填的表"。**

## 0.3 三个示范句（给用户看的，你照着理解意图）

> **① "给我一份 check list，我们要对照着打勾，写评语。"**
> **② "一份验收表，逐项验收并评价，另有评论区我要打字。"**
> **③ "批注表，我要按段落批注。"**

**——这三个句式覆盖三种交互形态。用户说别的，你也照这三种的骨架变。**

## 0.4 挂表长什么样（**照抄这一份，别自己发明**）

**参考实现**：`accept.html`（同仓库根目录，19 KB，**是唯一被验证过的挂表**）。

**它由五条链组成，一条都不能少**：

| # | 链 | 在 `accept.html` 里对应 |
|---|---|---|
| **1** | **标题 + 说明** | `<h1 id="sheetTitle">` + `.note` |
| **2** | **可勾选的行**（每行：勾选 + 备注） | `<table id="grid">` |
| **3** | **自由文本区**（可多个，如 评论区/优化区/话痨区） | 三个 `<textarea>` |
| **4** | **[提交] 按钮 → POST** | `fetch('/dsh-fou/accept', {method:'POST', …})` |
| **5** | **草稿自动存**（localStorage，刷新不丢） | `saveDraft()` / `loadDraft()` |

**第 4 条是最容易漏的** —— **漏了它，你得到的就是"纯 html"，不是挂表。**

> # **判据：没有"提交后落盘"的表，不算挂表。**

## 0.5 怎么算做对了（当场能验）

1. **挂板里能看到它**（打开挂板 → 有这一条，标着「验收表 / 批注表 / 清单」之类）
2. **能勾、能写字**（鼠标点得动）
3. **点提交 → 有回应**（页面提示已保存 / 或生成了文件）
4. **`D:\dsh-work\_挂板\` 下多了文件**（`.json` + `.md`）

**四条全中才算成。** 只中前两条 = 你造的只是个网页。

## 0.6 做错了怎么办

| 现象 | 原因 | 怎么修 |
|---|---|---|
| **挂板里是个纯网页，勾不了** | **自己发明了 HTML 结构** | 回去照 §0.4 五条链重做，或直接复制 `accept.html` 改内容 |
| **能勾，但点提交没反应** | **没有 POST 那一步** | 加 `fetch` 到 `/dsh-fou/accept`（或你自己的路由） |
| **提交了，但没文件** | **POST 的 body 格式不对** | 照 `accept.html` 的提交体抄 |
| **挂板里根本没有** | **只生成了文件，没链接到挂板** | 调 `POST /dsh-fou/hang` 把它挂上去（见 §三） |
| **刷新后填的东西没了** | 没做草稿自动存 | 加 `localStorage` 存/读 |

> **挂板的能力是「挂」；它只管挂得住、看得见，不管挂的是什么。**

## 第二章 形式开放（核心决定）

**挂件类型**：

| kind | 内容 | 落盘 |
|---|---|---|
| `html` | 一页 HTML（**挂表就在这一类**） | ✅ 存内容 |
| `md` / `text` / `json` | 文本 | ✅ 存内容 |
| `path` 类（md/html 用 `path`） | **只读引用一个文件** | ❌ **不复制**，改了就变 |
| **`url`** | **只记地址** | ❌ **不复制，永远最新** |

**认不出的 `kind` 一律当 `text`，不报错** —— **"挂"不该因为格式失败。**

## 挂表是 `html` 的一个**子集**（2026-11-10 明确）

**挂表 = `kind:"html"` 且 `form: true`。**

```json
{ "id": "…", "title": "…", "kind": "html", "file": "x.html",
  "form": true, "formKind": "accept" }
```

**`formKind` 是**自由文本**（`accept` / `annotate` / `review` / `reply` / 你自己起的名字都行）
—— 挂板只拿它做首标签，**认不出的照样显示原值，不会隐藏。**

> # **我们定的只是"进门的规矩"，不是"屋里的摆法"。**
> **——鼓励用户创造自己的挂表。**

## 第三章 外部 URL 可作为挂件

**契约**：

```
POST /dsh-fou/hang
headers: { "x-dsh-fou": "1", "content-type": "application/json" }
body: { "title": "任意标题", "kind": "url", "url": "http://127.0.0.1:端口/" }
→ 200 { "ok": true, "panel": { id, title, kind:"url", url, hungAt } }
```

**规则**：

1. **`kind:url` 只记地址，不复制内容** → 服务改了它跟着变
2. **`url` 挂件不落文件** → 挂板上显示的是 iframe 直连该地址
3. **任何 HTTP 地址都可以**（本机服务 / 外网页面）
4. **同一 `id` 重挂 = 覆盖**（不重复出现）

**验证过的实例（2026-11-06）**：

| 挂件 | 地址 | 用途 |
|---|---|---|
| `pedia-docs-8799` | `http://127.0.0.1:8799/` | 百科的官方文档搜索（649 篇） |
| `accept-*` | `/dsh-fou/accept?sheet=…` | 验收表（本插件自己的页面） |

## 第四章 链接入口：右键「在浮游打开」

> **任何在 DSH 界面里可右键的链接，菜单里应有一项「在浮游打开」；**
> **选中后，等价于调一次 `hang({ kind:'url', url: <该链接> })`。**

**与官方的差异（不是重叠）**：

| | 官方「在侧边栏打开」 | **「在浮游打开」** |
|---|---|---|
| 多标签 | ✅ | ✅（挂板可并列） |
| 退出保存 | ✅ | ✅（index.json） |
| **换会话还在吗** | ❌ **没了** | ✅ **还在** |

> **差异只有一条，但它是根：右栏跟会话，浮游跟人。**

**实现约束**：

1. **只做右键，不做左键单击**
2. **不改官方菜单的既有三项**
3. 若官方将来自己加「在浮游打开」，**让官方**（见总纲 §三④）

**✅ 已实现（2026-11-08）**：真实目标家族是 `url`（值 `{sessionId,url}`）/ `file` / `directory` / `image` / `tab` / `session`；`resolve` 收到的是 **`value` 直接体**。

## 第五章 挂上去之后怎么活（L2）

**两条约定，别的一条都不用管**：

## 5.1 结果落盘：挂件自己 POST 自己的路由

**挂板不帮忙存档** —— 它不知道你的数据长什么样。

**挂表的参考实现**：`POST /dsh-fou/accept` → 写成 `<时间>.json` + `<时间>.md`，并更新 `latest`。

## 5.2 要通知会话：发一条 `fou:` 开头的消息

```js
window.parent.postMessage({ type: 'fou:your-event', … }, window.location.origin);
```

- **`type` 必须以 `fou:` 开头** —— 挂板会原样往上转一层给浮游
- **已知可用**：`fou:accept-saved`（{ notify, notifyName, summary, mdPath }）

## 5.3 通知对象从哪来：URL 参数

**浮游打开挂板时会带** `?notify=<会话id>&notifyName=<名字>`，**挂板自动转给 `url` 挂件**。

> **只对 `/dsh-fou/` 自家页面转交**（不外泄到第三方 URL）。

## 第六章 五条纪律

1. **软依赖** —— 挂板不在，你的东西照样能用
2. **不替你容错** —— 挂件内部报错由挂件自己负责
3. **链接用 `/` 不用 `\`** —— markdown 的 `\_` 会吃掉下划线
4. **内容上限 4 MB** —— 超了报错，不静默截断
5. **`type` 必须 `fou:` 开头** —— 否则不转发
