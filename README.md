# dsh-fou · 浮游

> **浮游（Fou，显示名「浮游」）是 DSH 之上的一层悬浮容器。**
> **它不属于任何一个会话 —— 它跟着你。**
>
> 本仓库是它的插件形态。包名 `@local/dsh-fou`（v0.3 起；旧名 `@local/dsh-courier`）。

**状态：早期版本（0.2.0），接口仍在变。** 详细的用法与协议见下。

---

## 一句话

> **别人做窗口，浮游做位置。**
> **官方装「内容」，浮游装「位置」—— 而位置的极端形态，就是一个能装任何东西的容器。**

---

## 它现在能做什么

| 能力 | 说明 |
|---|---|
| **三形态** | 圆球 / 胶囊 / 全窗，可拖动、可记忆 |
| **聊天** | 不离开当前页面，给当前会话发一条消息 |
| **穿越** | 点一下就在会话之间移动（左键） |
| **开间** | 一个只装一件的容器：能装**网页**、**文件**、**插件界面**（右键） |
| **最近打开** | 回到刚才看过的东西 |
| **挂靠** | 插件可以把界面**挂进开间**（硬挂载），或给浮游一个**动作**（遥控） |
| **挂板** | 一个可挂任意件的地方（HTML / md / JSON / URL） |
| **编辑器** | 编辑即保存、发送即落稿 |

## 目录

```
client.js          客户端半（浮游的界面与坞口协议）
index.js           宿主半（同源路由：挂板、稿件、编辑器页面）
view.html          开间的"查看页"（渲染 md / html / 纯文本）
editor.html        编辑器页面
panels.html        挂板页面
accept.html        验收表（一种"模表"）
docs/              协议
skill/             给 Agent 的接入 skill
```

---

## 它不是什么

- **不做工作台** —— 一个小球就够了。
- **不做标签页** —— 一次只看一件。
- **不替代浏览器** —— 装 URL 是为了"带你去现场"，不是为了"替代你上网"。
