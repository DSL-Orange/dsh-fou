## 一、一句话

> **挂板的能力是「挂」；它只管挂得住、看得见，不管挂的是什么。**

---

## 二、形式开放（核心决定）

**挂件类型**：

| kind | 内容 | 落盘 |
|---|---|---|
| `html` | 一页 HTML | ✅ 存内容 |
| `md` / `text` / `json` | 文本 | ✅ 存内容 |
| `path` 类（md/html 用 `path`） | **只读引用一个文件** | ❌ **不复制**，改了就变 |
| **`url`** | **只记地址** | ❌ **不复制，永远最新** |

**认不出的 `kind` 一律当 `text`，不报错** —— **"挂"不该因为格式失败。**

---

## 三、外部 URL 可作为挂件（2026-11-06 新增）

**契约**：

```
POST /dsh-fou/hang
headers: { "x-dsh-fou": "1", "content-type": "application/json" }
body: { "title": "任意标题", "kind": "url", "url": "http://127.0.0.1:端口/" }
→ 200 { "ok": true, "panel": { id, title, kind:"url", url, hungAt } }
```

**规则**：

1. **`kind:url` 只记地址，不复制内容** → 服务改了它跟着变
2. **`url` 挂件不落文件** → 挂板上显示的是 iframe 直连该地址
3. **任何 HTTP 地址都可以**（本机服务 / 外网页面）
4. **同一 `id` 重挂 = 覆盖**（不重复出现）

**已验证的实例（2026-11-06 16:00）**：

| 挂件 | 地址 | 用途 |
|---|---|---|
| `pedia-docs-8799` | `http://127.0.0.1:8799/` | 百科的官方文档搜索（649 篇） |
| `accept-*` | `/dsh-fou/accept?sheet=…` | 验收表（本插件自己的页面） |

**这就是"官方浮窗做不到、挂板能做到"的那条**：**官方浮窗只装文件；挂板能装 URL 与活页面。**

## 四、链接入口（2026-11-06 新增，待实现）

**需求（用户原话）**：

> **"左键单击/右键选择 URL 直接在浮游中打开。我预估这是低本高收的。"**

**契约（要有，先定）**：

> **任何在 DSH 界面里可右键的链接，菜单里应有一项「在浮游打开」；**
> **选中后，等价于调一次 `hang({ kind:'url', url: <该链接> })`。**

**与官方的差异（不是重叠）**：

| | 官方「在侧边栏打开」 | **「在浮游打开」** |
|---|---|---|
| 多标签 | ✅ | ✅（挂板可并列） |
| 退出保存 | ✅ | ✅（index.json） |
| 标签页↔浮窗互转 | ✅ | ✅（挂板本身就是浮游里的） |
| **换会话还在吗** | ❌ **没了** | ✅ **还在** |

> **差异只有一条，但它是根：右栏跟会话，浮游跟人。**

**实现约束（先写死，防止越界）**：

1. **只做右键，不做左键单击** —— 左键单击会破坏"点链接用浏览器打开"的预期
2. **不改官方菜单的既有三项**（在侧边栏打开 / 外部浏览器 / 复制链接）
3. 若官方将来自己加「在浮游打开」，**让官方**（见总纲 §三④ 协议先行）

## 五、挂上去之后怎么活（L2）

**两条约定，别的一条都不用管**：

### 5.1 结果落盘：挂件自己 POST 自己的路由

**挂板不帮忙存档** —— 它不知道你的数据长什么样。

### 5.2 要通知会话：发一条 `fou:` 开头的消息

```js
window.parent.postMessage({ type: 'fou:your-event', … }, window.location.origin);
```

- **`type` 必须以 `fou:` 开头** —— **挂板会原样往上转一层**给浮游
- **已知可用**：`fou:accept-saved`（{ notify, notifyName, summary, mdPath }）

### 5.3 通知对象从哪来：URL 参数

**浮游打开挂板时会带** `?notify=<会话id>&notifyName=<名字>`，**挂板自动转给 `url` 挂件**。

> **只对 `/dsh-fou/` 自家页面转交**（不外泄到第三方 URL）。

---

## 六、五条纪律

1. **软依赖** —— 挂板不在，你的东西照样能用
2. **不替你容错** —— 挂件内部报错由挂件自己负责
3. **链接用 `/` 不用 `\`** —— markdown 的 `\_` 会吃掉下划线
4. **内容上限 4 MB** —— 超了报错，不静默截断
5. **`type` 必须 `fou:` 开头** —— 否则不转发
